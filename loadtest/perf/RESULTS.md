## 해석

- 지금 데이터 규모에서는 API 응답 시간 대부분이 HTTP·JSON 처리라, 쿼리 개선이 응답 시간에 주는 차이는 몇 ms. p95 는 측정마다 ±3ms 흔들림
- 그래도 고친 이유: N+1 은 페이지 크기만큼, 전체 스캔은 회차가 쌓이는 만큼(1년 약 5,500개) 비용이 늘어남. 인덱스 후 검사 행은 데이터 양과 무관하게 그날·그 주 회차 수
- 순번 일괄 계산 결과는 테스트회원 대기 21건을 SQL 윈도 함수(`ROW_NUMBER`)로 계산한 값과 모두 일치
